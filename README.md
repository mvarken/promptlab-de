# PromptLab DE – Prompt Gallery

Kostenlose, mobiloptimierte KI-Prompt-Galerie mit Suche, Kategorien, Detailansicht und Kopieren-Buttons.

## Live-Adresse
https://mvarken.github.io/promptlab-de/

## Einrichtung
1. GitHub → Settings → Pages.
2. Unter **Build and deployment** als Source **GitHub Actions** wählen.
3. In Actions den Workflow **Deploy GitHub Pages** ausführen, falls er nicht automatisch startet.

## Prompts ergänzen
In `index.html` im JavaScript-Array `prompts` einen weiteren Eintrag mit `id`, `title`, `category`, `emoji`, `desc` und `prompt` ergänzen.

## Bilder
Diese erste online veröffentlichte Fassung nutzt illustrative Symbole als Platzhalter. Echte Beispielbilder können später im Verzeichnis `assets/` ergänzt und in den Karten referenziert werden. Es werden keine privaten Referenzfotos veröffentlicht.
